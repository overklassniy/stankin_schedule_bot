# handlers

Обработчики aiogram-роутеров — команды пользователя, callback-запросы и события чата.

Пакет собирает все роутеры в один `Router(name="main")` через `__init__.py`, который затем подключается к диспетчеру в `bot.py`.

## Содержимое

- `__init__.py` — сборка главного роутера и подключение вложенных роутеров.
- `group_bind.py` — привязка и отвязка чата при добавлении/удалении бота (событие `my_chat_member`).
- `schedule.py` — команды `/schedule`, `/s`, `/tomorrow`, `/t` и обработка кнопки «Завтра».
- `settings.py` — команда `/settings`, inline-кнопки настроек и FSM для ввода кода группы и времени отправки.
- `code.py` — команда `/code` со ссылкой на исходный код проекта.
- `private.py` — приветственное сообщение в личных сообщениях с ботом.
