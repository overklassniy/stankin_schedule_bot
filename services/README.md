# services

Бизнес-логика и внешние интеграции бота.

Содержит модули для работы с Moodle, кэширования расписания и ежедневной отправки по расписанию. Не зависит от aiogram напрямую — вызывается из хендлеров и точки входа `bot.py`.

## Содержимое

- `__init__.py` — экспорт функции скачивания PDF для использования другими пакетами.
- `moodle_client.py` — гостевой вход на Moodle, поиск PDF по коду группы и скачивание файла расписания.
- `schedule_cache.py` — гибридный кэш: PDF на диске с TTL и распарсенный результат в памяти с инвалидацией по сигнатуре файла (mtime + size).
- `scheduler.py` — фоновый планировщик ежедневной отправки расписания подходящим группам с защитой от повторной отправки.
