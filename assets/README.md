# assets

Статические ассеты для оформления репозитория.

Содержит графические материалы, используемые в `README.md` и других Markdown-файлах проекта. Не относится к runtime-данным бота.

## Содержимое

- `readme/hero.svg` — главный баннер корневого `README.md`.

## Примечания

- Ассеты предназначены только для документации и не используются ботом во время работы.
- Для изображений, отправляемых в чат, используется директория `images/`.
