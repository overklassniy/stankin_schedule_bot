# utils

Вспомогательные утилиты проекта.

Содержит инфраструктурные функции (логирование, работа с JSON, вычисление дат) и парсер PDF-расписаний. Не содержит бизнес-логики бота — только переиспользуемые инструменты.

## Содержимое

- `basic.py` — настройка логирования, загрузка и сохранение JSON, вычисление смещения даты для команд `/s` и `/t`.
- `parser.py` — парсинг PDF через camelot: извлечение таблиц, объединение строк лабораторных по подгруппам (`fix_labs`), фильтрация пар по датам и периодам (`get_today_schedule`) и форматирование HTML-сообщения.
