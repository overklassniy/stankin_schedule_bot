# Поддержка

## Где получить помощь

| Канал | Назначение |
| ----- | ---------- |
| [Issues](https://github.com/overklassniy/stankin_schedule_bot/issues) | Сообщения об ошибках, предложения и вопросы по использованию |
| [SECURITY.md](SECURITY.md) | Приватные сообщения об уязвимостях |

## Перед обращением

1. Проверьте [документацию](docs/) — возможно, ответ уже есть:
   * [Установка](docs/installation.md)
   * [Конфигурация](docs/configuration.md)
   * [Использование](docs/usage.md)
   * [Архитектура](docs/architecture.md)
2. Поищите среди существующих
   [issues](https://github.com/overklassniy/stankin_schedule_bot/issues?q=is%3Aissue).
3. Если вопрос не решён — откройте новый issue, выбрав подходящий шаблон
   на странице
   [New issue](https://github.com/overklassniy/stankin_schedule_bot/issues/new/choose)
   (например, форму «Вопрос по использованию»).

## Что указывать в обращении

* Версия Python и операционная система.
* Способ запуска: локально или Docker.
* Код группы и команда, на которой возникла проблема.
* Логи из папки `logs/` (без секретов и токенов).
* Шаги для воспроизведения.

## Коммерческая поддержка

Проект поддерживается на добровольной основе. Гарантированных сроков
реагирования нет, но мы стараемся отвечать оперативно.
