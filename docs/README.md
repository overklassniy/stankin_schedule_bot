# docs

Подробная документация проекта.

Дополняет корневой `README.md` развернутыми описаниями установки, конфигурации, использования и архитектуры бота.

## Содержимое

- `installation.md` — системные требования, установка из исходников, Ghostscript и запуск через Docker.
- `configuration.md` — переменные окружения `.env` и параметры `config.json`.
- `usage.md` — команды бота и пользовательские сценарии.
- `architecture.md` — устройство бота, поток данных, структура пакетов и схема БД.
