# Использование

## Первый запуск

1. Добавьте бота в группу Telegram (или супергруппу).
2. Бот автоматически привяжет чат и пришлёт сообщение:
   > Чат «Название» привязан к боту. Настройте расписание: /settings (только для админов).

3. В группе выполните `/settings` и нажмите кнопку **«Группа»** — введите код вашей группы (например, `ИДБ-24-10`). Код должен совпадать с именем PDF-файла на Moodle (без расширения).

4. При необходимости настройте **время отправки**, **картинки**, **кнопку «Завтра»**.

5. Нажмите **«Проверить загрузку»** — бот скачает PDF с Moodle, распарсит и сообщит количество пар на сегодня.

## Команды

### `/schedule` (псевдоним `/s`)

Расписание на текущий день. Поддерживает аргументы:

- `/s` — сегодня
- `/s 1` — завтра (смещение в днях)
- `/s -1` — вчера
- `/s 25.12` — конкретная дата (дд.мм)

Доступна только в привязанных к боту группах.

### `/tomorrow` (псевдоним `/t`)

Расписание на завтра. Эквивалент `/s 1`.

### `/settings`

Открывает inline-клавиатуру с настройками группы. Доступна:

- глобальным админам (из `ADMIN_IDS` в `.env`),
- создателю и администраторам группы (для group/supergroup).

Кнопки:

- **Группа** — ввести код группы
- **Время** — ввести время отправки в формате `ЧЧ:ММ`
- **Картинки** — включить/выключить отправку изображений
- **Кнопка «Завтра»** — включить/выключить inline-кнопку под ежедневным сообщением
- **Проверить загрузку** — скачать и распарсить PDF, проверить, что расписание доступно

### `/settopic`

Привязывает расписание к текущему топику супергруппы. Выполните команду внутри нужного топика — бот будет отправлять расписание туда. Если выполнить в общем чате (не в топике), привязка снимается.

### `/code`

Присылает ссылку на исходный код бота на GitHub.

## Личные сообщения

В личном чате бот отправляет приветствие со списком команд и ссылкой на GitHub. Основная функциональность (расписание) работает только в привязанных группах.

## Автоматическая отправка

Планировщик проверяет время каждые `CHECK_TIME_INTERVAL` секунд. Когда текущие час и минута совпадают с настройками группы, бот:

1. Скачивает PDF с Moodle (если кэш устарел).
2. Парсит расписание через camelot.
3. Формирует HTML-сообщение с парами на день.
4. Отправляет в чат группы (с учётом топика).
5. Если включены картинки — отправляет фото со случайным изображением из `IMAGES_DIR` и подписью.
6. Если включена кнопка «Завтра» — добавляет inline-кнопку под сообщением.

Каждая группа получает расписание не более одного раза в день.

## Воскресенье

По воскресеньям бот не отправляет расписание. При ручном запросе `/s` в воскресенье приходит сообщение «Воскресенье. Занятий нет!».

## Формат сообщения

Каждая пара оформлена как HTML-цитата (`<blockquote>`) с полями:

- название предмета
- преподаватель (полное имя из `teachers.json` или инициалы)
- тип занятия (лекция / семинар / лабораторная работа)
- кабинет или «Онлайн»
- период проведения (`01.09 - 31.12`)
- время пары (например, `8:30 - 10:05`)

Для лабораторных работ по подгруппам дополнительно указывается номер подгруппы и объединённое время.
