# db

Слой работы с SQLite через aiosqlite.

Хранит настройки групп и список админов. Предоставляет асинхронные функции CRUD, используемые хендлерами и планировщиком.

## Содержимое

- `__init__.py` — экспорт функций инициализации БД и операций с группами/админами.
- `database.py` — инициализация базы данных, подключение и схема таблиц `groups` и `admins`.
- `models.py` — операции CRUD: создание и удаление групп, обновление настроек, проверка админа, разрешение группы по `chat_id` + `thread_id`.

## Схема БД

Таблица `groups` — настройки чатов (код группы, время отправки, картинки, кнопка «Завтра»).
Таблица `admins` — Telegram user id пользователей с доступом к настройкам.
